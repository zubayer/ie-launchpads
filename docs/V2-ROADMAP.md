# IE Launchpad V2 roadmap

## Non-negotiables
Do not write to the original repository or change its deployment. Preserve original routes, concept IDs and 28 simulators. Do not claim that AI output is professionally verified. Do not expose API keys or transmit personal data without consent.

## Phase 1 — implemented foundation (build, tests and browser audit pass as of 2026-11-24; see IMPLEMENTATION-STATUS.md)
Engineering Academy with source directory, software pathways, mission datasets, local checklists and bottleneck exercise; optional provenance metadata; finite-number checks; isolated local storage.

## Phase 2 — curriculum and verification
Map all existing domains to IISE knowledge areas. Audit each of the 494 concepts. Add math foundations, production operations, product development, information engineering, data center engineering, applied AI, leadership, HCI. Add prerequisites, precise source sections, assumptions, units, independent calculations and review dates. Never mark source-checked without actual review.

## Phase 3 — learning engine
Beginner, academic, workplace and interview modes; numeric and open-response problems, feedback, error notebook, spaced retrieval and transfer tasks. Separate recall from application and portfolio evidence. Require accessible controls, versioned backups and validated imports.

## Phase 4 — professional workbench
Excel, SQL, Python, Power BI, Minitab, optimization, simulation, CAD and PLC tutorials; 12+ realistic missions, datasets, rubrics, editable templates, deliverables and portfolio exports. Clearly label synthetic data and simulated projects. Add factory, layout, scheduling, value stream, automation and economic decision labs.

## Phase 5 — career and AI
Industry pathways, occupational skill mapping, transparent job readiness, evidence-backed resume coaching. Ground tutor responses in reviewed sources; use deterministic calculations. Optional server-side AI with rate limits, privacy controls and no frontend secrets. Optional accounts and sync only when needed.

## Acceptance gates
- npm ci, npm test and npm run build pass
- All existing routes and new routes pass keyboard/mobile/browser tests
- No broken concept IDs, source URLs or invalid numeric answers
- Assessment rubrics distinguish recall, computation and application
- No old-repository writes; independent Vercel project
- WCAG 2.2 AA target, explicit assumptions, license-aware sources
- No placeholder buttons or claims of completed work without tests
