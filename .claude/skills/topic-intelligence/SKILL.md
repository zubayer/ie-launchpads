name: topic-intelligence
description: Enrich an existing IE Launchpad topic with authentic sources, visual intuition, evidence-based assessments and validated engineering math.
---

Read AGENTS.md, docs/TOPIC-STUDIO-ROADMAP.md, and the generated topic inventory. Locate the stable topic ID; reuse current components before adding anything. Audit actual fields, identify the highest-value learning gap, and create only authentic content.

1. Lesson enrichment: write a concise core idea, concrete mental model, objectives, prerequisites, assumptions, common mistakes, application, comparison and interview answer. Distinguish illustrative cases and documented evidence.
2. Source verification: open the actual relevant section, map specific claims to existing source records, check URL/title/access/date, respect reuse licenses, and never claim human expert review.
3. Visual design: choose a model appropriate to the concept; prefer SVG, labeled controls, accessible descriptions, text equivalents and reduced motion.
4. Engineering math QA: derive formulas with units, independent reference values and edge cases; test actual model results, not copies of implementation. Label limitations.
5. Assessment: use stable IDs and existing recordAttempt/logMistake. No mastery from mere clicks.
6. Release review: run tests, build, docs, size and browser audit; check real interactions and mobile; document pending issues. No production merge on failure.
